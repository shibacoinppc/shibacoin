## 新的官方仓库

ShibaCoin 当前及未来的所有开发工作都在以下地址进行：

**https://github.com/ShibaCoinPOW**

请使用新仓库获取最新的源代码和发布版本，并在新仓库中提交问题报告和拉取请求。

## 迁移原因

本账户（ShibaCoinPPC）由 ShibaCoin 的原始创始人单独拥有。因此，当前开发团队无法任命新的维护者，也无法在此账户下创建新的仓库。为了让 ShibaCoin 的开发得以继续并保障其未来，团队创建了一个由团队自己管理的新 GitHub 账户：ShibaCoinPOW（工作量证明，Proof of Work）。

## 关于本仓库

本仓库中的代码仅作为历史参考保留，将不再接收更新、修复或新版本。请不要在此处提交新的问题或拉取请求，请改为提交到新仓库。
