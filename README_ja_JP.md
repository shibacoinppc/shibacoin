**ShibaCoin の開発は移行しました。このリポジトリは現在、積極的にメンテナンスされていません。**

## 新しい公式リポジトリ

ShibaCoin の現在および今後のすべての開発は、以下で行われます。

**https://github.com/ShibaCoinPOW**

最新のソースコードやリリースの入手、Issue の報告、プルリクエストの提出には、新しいリポジトリをご利用ください。

## 移行の理由

このアカウント（ShibaCoinPPC）は、ShibaCoin の創設者が単独で所有しています。そのため、現在の開発チームは新しいメンテナーを任命することも、このアカウントで新しいリポジトリを作成することもできません。ShibaCoin の開発を継続し、その将来を確保するため、チームは自らが管理する新しい GitHub アカウント ShibaCoinPOW（Proof of Work、プルーフ・オブ・ワーク）を作成しました。

## このリポジトリについて

このリポジトリのコードは、過去の記録として参照用にのみ保管されています。今後、更新、修正、新しいリリースは行われません。新しい Issue やプルリクエストはここではなく、新しいリポジトリに提出してください。
