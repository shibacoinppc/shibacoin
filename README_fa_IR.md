**توسعه ShibaCoin منتقل شده است. این مخزن دیگر به‌طور فعال نگهداری نمی‌شود.**

## مخزن رسمی جدید

تمام توسعه‌های فعلی و آینده ShibaCoin در آدرس زیر انجام می‌شود:

**https://github.com/ShibaCoinPOW**

لطفاً برای دریافت آخرین کد منبع و نسخه‌ها، و همچنین ثبت گزارش مشکلات (issues) و درخواست‌های ادغام (pull requests)، از مخزن جدید استفاده کنید.

## دلیل انتقال

این حساب (ShibaCoinPPC) تنها در مالکیت بنیان‌گذار اصلی ShibaCoin است. به همین دلیل، تیم توسعه فعلی نمی‌تواند نگهدارندگان جدیدی تعیین کند یا مخزن جدیدی در این حساب ایجاد کند. برای ادامه توسعه ShibaCoin و تضمین آینده آن، تیم یک حساب جدید در GitHub با نام ShibaCoinPOW (اثبات کار، Proof of Work) ایجاد کرده است که تحت کنترل خود تیم است.

## این مخزن

کد موجود در این مخزن فقط برای مرجع تاریخی نگهداری می‌شود و دیگر به‌روزرسانی، اصلاح یا نسخه جدیدی دریافت نخواهد کرد. لطفاً issue یا pull request جدیدی در اینجا ثبت نکنید و آن‌ها را به مخزن جدید ارسال کنید.
