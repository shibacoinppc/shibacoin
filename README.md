ShibaCoin (Archived Repository)

Development of ShibaCoin has moved. This repository is no longer actively maintained.

New Official Repository

All current and future ShibaCoin development takes place at:

https://github.com/ShibaCoinPOW

Please use the new repository for the latest source code, releases, issue reports, and pull requests.

Why the Move

This account (ShibaCoinPPC) is owned solely by the original founder of ShibaCoin. Because of this, the current development team cannot appoint new maintainers or create new repositories under this account. To keep ShibaCoin development going and secure its future, the team has created a new GitHub account, ShibaCoinPOW (Proof of Work), which it controls.

This Repository

The code in this repository is kept for historical reference only. It will not receive updates, fixes, or new releases. Please do not open new issues or pull requests here; submit them to the new repository instead.
